Detailed Description

Zero-dependency UTF-8 encoding, decoding, grapheme-cluster navigation, and Unicode word/input classification utilities.

Used by Text, TextInput, and TextArea so that cursor movement, deletion, selection, word-wrapping, and ellipsis truncation always operate on valid UTF-8 codepoint / grapheme-cluster boundaries rather than raw bytes.
