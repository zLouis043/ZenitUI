Detailed Description

A boolean checkbox with a drawn check mark.

The visual is drawn directly by renderContent (a filled rounded rect for the box, plus a small white square for the check mark when checked). Theme rules can override both through the ::box and ::mark pseudo-elements.

Warning
This component does not call setChecked in its onClick handler, unlike Toggle. As a result, the :checked pseudo-class is never set from user interaction; only an explicit setChecked() call from application code will trigger it. If you want Checkbox:checked { ... } to work, use Toggle or patch the component to call setChecked(isChecked) after the state flip. See Toggle for the intended pattern.
