Detailed Description

Abstract 2D rendering backend.

All coordinates, rectangles, radii, and font sizes are expressed in logical pixels (post-DPI). Backends apply dpiScale internally when configuring the GPU transform or physical scissor rect.

See Writing a Custom Backend for the full porting guide and Backends, TextEngine, UTF-8 & Debugging for reference implementations (RaylibRenderer, MockRenderer).

TextureHandle tex = {} )
pure virtual

Draw an indexed triangle list in logical screen coordinates.

This is the single mandatory geometry primitive for backends. When tex.valid() is false, backends should sample a 1x1 opaque white texture so solid-colored vertices render unmodified.

Triangles are emitted counter-clockwise in NDC (Y-down screen space) by all Geometry2D builders.

Implemented in ZenitUI::RaylibRenderer, ZenitUI::SDL3Renderer, and ZenitUI::Test::MockRenderer.
