Detailed Description

A push button.

Style tag: "Button". Inherits from Panel so it shares its raycast and chrome behaviour. Emitted :pressed / :hover / :focused states match the underlying InputController lifecycle.

The button is keyboard-activatable: Enter and Space fire onClick when the button has focus.

◆ setText()

void ZenitUI::UI::Button::setText ( const std::string & s)
inline

Update the label text.

If the first child is a Text, replaces its content. Otherwise, adds a new Text labeled with the given string as the last child. Note that adding a label after a non-Text child will make text() (which only inspects the first child) return empty — this is a known wart of the current implementation; Btn sets the label first so it is not usually a problem in practice.
