Detailed Description

Debug-only inspection helpers (tree dump, style dump, theme dump).

When ZENITUI_DEBUG is defined, this header provides real implementations of the dump functions. When it is not defined, the same symbols exist but are no-ops, so calling code does not need #ifdefs.

Typical use:

#include "Debug.hpp"
// In a key handler:
ZenitUI::Debug::dumpTree(root);
ZenitUI::Debug::dumpStyle(*someNode);
ZenitUI::Debug::dumpTheme();
Debug.hpp
