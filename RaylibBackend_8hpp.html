Detailed Description

Reference Raylib implementation of IPlatform, IRenderer, and IAssetProvider.

Links against Raylib via the ZenitUI::RaylibBackend CMake target. Supports shaders (Feature::Effects), nested render targets (Feature::NestedTargets), sub-rect target blits (Feature::TargetSubRect), per-glyph measureCodepoint, and configurable CodepointSet font-atlas baking.
