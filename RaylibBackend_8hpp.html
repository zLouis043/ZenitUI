Detailed Description

Reference Raylib implementation of ZenitUI's three backend interfaces: IPlatform, IRenderer, and IAssetProvider.

Use this file (together with RaylibBackend.cpp) as the blueprint when porting ZenitUI to another graphics or windowing library (SDL, GLFW+bgfx, Sokol, custom engine, etc.). Every backend consists of three independent pieces wired into UIContext:

  1. Platform (IPlatform) — window size, DPI scale, monotonic clock, pointer/keyboard polling, safe-area insets, and system clipboard.
  2. Renderer (IRenderer) — 2D primitives, textures/nine-slice, text drawing & measurement, transform/clip/shader stacks, and optional off-screen render targets for post-processing filters.
  3. Asset Provider (IAssetProvider) — loading, caching, name-based lookup, and unloading of fonts, textures, and shaders.

Links against Raylib via the ZenitUI::RaylibBackend CMake target. Advertises Feature::Effects, Feature::NestedTargets, and Feature::TargetSubRect.
