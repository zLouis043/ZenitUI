Detailed Description

Ready-to-use UI components in ZenitUI::UI.

Built-in widgets expose a style tag matching their class name (Button, TextInput, TextArea, Slider, Dropdown, …) and optional pseudo-element parts (::track, ::fill, ::knob, ::cursor, ::selection, ::placeholder) that can be themed from .zstyle without subclassing.

Live examples: 03_widgets · 08_portals · 10_canvas

Live examples
  • 00_demo — Flagship ZenitUI showcase: live Dark/Light theming, ZMarkup prefabs & keyed Each, Bindable<T>, UTF-8 TextArea, 10k-row VirtualView, portals, filters, and CanvasLayout.
  • 03_widgets — Interactive gallery of built-in widgets (Button, Toggle, Checkbox, Slider, ProgressBar, TextInput, Dropdown) inside a ScrollView.
  • 08_portals — Portal-backed overlays (Tooltip, Popup, ContextMenu) escaping parent clipping alongside a full-screen Modal.
  • 09_custom_widget — Custom Rating widget derived from TLayout<Derived>, demonstrating computeIntrinsicSize, renderContent with ::part, pointer/keyboard input, and ZMarkup registration.
  • 10_canvas — Explicit offscreen composition with CanvasLayout, comparing an unshaded target against a whole-canvas shader via setShader().

◆ setText()

void ZenitUI::UI::Button::setText ( const std::string & s)
inline

Update the label text.

If the first child is a Text, replaces its content. Otherwise, adds a new Text labeled with the given string as the last child. Note that adding a label after a non-Text child will make text() (which only inspects the first child) return empty — this is a known wart of the current implementation; Btn sets the label first so it is not usually a problem in practice.

◆ setUniformHeight()

void ZenitUI::UI::VirtualView::setUniformHeight ( float px)
inline

Set a uniform height for all items.

When positive, disables measurement — this makes huge lists cheap (O(1) height computation), at the cost of assuming all items have the same height. 0 restores measurement mode.
