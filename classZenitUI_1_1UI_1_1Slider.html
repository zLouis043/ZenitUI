Detailed Description

A [0, 1] slider with keyboard and pointer control.

Style tag: "Slider". Default intrinsic size: 120 x max(24, 1.2*fontSize). Parts: ::track, ::fill, ::knob.

Examples
00_demo/main.cpp, and 12_bindable/main.cpp.

◆ onUpdate()

void ZenitUI::UI::Slider::onUpdate ( float )
inlineoverrideprotectedvirtual

Handle keyboard stepping and pointer dragging.

Keyboard handling runs whenever the node has focus (regardless of pointer state); pointer handling captures the pointer on first state.pressed and releases on button-up (which happens implicitly in Layout::updateTree).
