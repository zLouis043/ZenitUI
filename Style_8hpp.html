Detailed Description

The Style / ComputedStyle pair and all style-related value types.

Style is a "sparse" style: every property is wrapped in Opt<T> so the resolver can tell "unset" apart from "set to the default value". This lets stylesheet rules and inline overrides be layered with overlay() without losing the inheritance information.

ComputedStyle is the "dense" form: every property has a concrete value, either taken from the resolved Style, inherited from the parent, or defaulted. The layout and render code only ever sees ComputedStyle.

BUBBLE_STYLE_PROPS is the single source of truth for the property list. Adding a property there propagates to Style, ComputedStyle, lerp, equality, overlay, serialization, and the propTable() used by tooling.
