Detailed Description

An off-screen rendering surface with optional post-effect.

CanvasLayout renders its entire subtree into an off-screen target, then blits the target into its own rect with an optional shader effect applied. This lets you build things that plain clip-and-draw cannot express:

  • content that spills outside its own rect and should be clipped to it;
  • per-subtree post-processing (effect from style, or a shader set via setShader) applied as a single pass;
  • transforms that would otherwise bleed into siblings.

The target is created lazily on first draw and re-created only when the canvas size changes. It is destroyed in the destructor.

Note
CanvasLayout::draw overrides the base implementation entirely: it does not apply CSS animations to the chrome (background, border, shadow), does not apply filters from the style, and does not draw scrollbars. If you need those, use a plain Layout with effect instead of a CanvasLayout.
Warning
The destructor dereferences UIContext::get().renderer without a null check after target.valid() returns true. If the renderer has already been destroyed when the canvas is destroyed (a shutdown-order bug), this will crash. Ensure canvases outlive their renderer or explicitly destroy them before tearing down the backend.
