Detailed Description

Reference IPlatform backed by SDL3 window, input, and clipboard APIs.

Registers an internal SDL_AddEventWatch listener on construction so edge-triggered mouse, wheel, keyboard, and UTF-8 text events are captured automatically whenever SDL_PollEvent runs — keeping the IPlatform interface strictly identical to polling backends like RaylibPlatform.
