Detailed Description

A single-line editable text field.

The input is a Stack with a single text cursor (no child Text node). All visual is drawn directly by renderContent: the text, the cursor caret (blinking at 1 Hz), and the selection highlight.

Editing model:

  • The text is stored as a std::string; the cursor is a byte offset (not a grapheme index). This is simple and correct for ASCII, but multi-byte UTF-8 codepoints are treated as multiple "characters" — arrows move by byte, backspace deletes one byte. Not Unicode-aware.
  • Only printable ASCII (32..126) can be inserted; pasted text is filtered to that range.

Interaction:

  • Click to place the cursor; double-click selects a word; triple-click selects all.
  • Drag to extend the selection.
  • Shift+arrows extend the selection; Ctrl+A selects all.
  • Ctrl+C/X/V: copy / cut / paste via IPlatform clipboard.
  • Ctrl+Z/Y: undo / redo (50-step history).
  • Enter: submits and releases focus; Escape: releases focus.
  • Home / End: jump to start / end; Shift extends.
Note
This component dereferences UIContext::platform in onUpdate (for time() and clipboard access) without a null check. If you use TextInput in a headless test or without a platform backend, you must set UIContext::get().platform to a valid mock, or the first onUpdate after the field is focused will crash.
