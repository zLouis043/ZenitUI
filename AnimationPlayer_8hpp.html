Detailed Description

Per-node owner of imperative and CSS animation state.

Every Layout embeds one AnimationPlayer (as anim_). It is responsible for:

  • Advancing imperative animations (tickImperative).
  • Keeping the CSS animation list in sync with the node's target style (syncCss, driven by Style::animations).
  • Advancing CSS animations (tickCss).
  • Sampling CSS animations onto a style at draw time (overlayCssStyle, overlayCssComputed).
  • Managing per-pseudo-element animations (applyCssToPart), which use wall-clock time (UIContext::time) instead of a per-frame delta.

The Anim namespace in AnimationPlayer.cpp holds the free functions that mutate ActiveCssAnimation lists; this header only declares them. The AnimationPlayer struct itself is the stateful facade.
