Detailed Description

Reference SDL3 + OpenGL 3.3 Core implementation of IPlatform, IRenderer, IAssetProvider, and IBackend.

Links against SDL3 and stb (fetched via CMake FetchContent) through the ZenitUI::SDL3Backend CMake target. Provides full feature parity with RaylibBackend:

  • Feature::Effects — GLSL 330 fragment shaders compatible with the .fs files in assets/shaders/.
  • Feature::NestedTargets — off-screen color-only RGBA FBOs.
  • Feature::TargetSubRect — sub-rectangle blits for TargetPool.
  • HiDPI scaling via SDL_GetWindowPixelDensity.
  • Zero extra event-pumping boilerplate on IPlatform (SDL3Platform hooks into SDL3's event queue transparently via SDL_AddEventWatch).
