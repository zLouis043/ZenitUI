Detailed Description

Per-application state: renderer, platform, pointer, focus, portals.

UIContext is a singleton (UIContext::get()) that aggregates every piece of mutable per-frame state the framework needs but does not want to thread through every call. It is the boundary between the platform layer (window, input, clock) and the framework (layout, style, render).

Two interface families live here:

  • IRenderer — abstract drawing backend. Concrete implementations target a specific GPU API or a software rasterizer; the framework never talks to a specific backend directly.
  • IPlatform / IAssetProvider — abstract input and asset backends.

UIContext itself holds:

  • The current frame's pointer / modifier / input snapshot.
  • Focus and pointer-capture ownership.
  • Hit-test and click-routing state.
  • The per-frame portal registry.
  • One-shot "was consumed" flags for buttons and the wheel.
