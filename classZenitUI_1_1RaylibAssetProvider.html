Detailed Description

Reference IAssetProvider for loading and caching Raylib fonts, textures, and shaders by logical name.

Uses CodepointSet::defaultLatin() by default when baking TTF/OTF font atlases via LoadFontEx. Customize defaultCodepoints() before loading fonts, or pass a per-font CodepointSet overload.
