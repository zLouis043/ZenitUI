Detailed Description

Pluggable backend implementations, Unicode utilities (Utf8, CodepointSet), logging, and debug dumps.

The core library depends solely on IPlatform, IRenderer, and IAssetProvider (optionally wrapped by IBackend for multi-backend apps). Browse page_available_backends for all built-in implementations, or follow Writing a Custom Backend to port ZenitUI to your own engine.

Use CodepointSet to control which UTF-8 glyph ranges are baked into font atlases, and ZenitUI::Debug (ZENITUI_DEBUG) to inspect live layout trees, styles, and render stats.

Live examples: 01_hello_world · 00_demo

Live examples
  • 00_demo — Flagship ZenitUI showcase: live Dark/Light theming, ZMarkup prefabs & keyed Each, Bindable<T>, UTF-8 TextArea, 10k-row VirtualView, portals, filters, and CanvasLayout.
  • 01_hello_world — Minimal Raylib setup, single Stack root layout, inline styling, and the runFrame/renderFrame loop.
  • 07b_effects_stress — GPU stress benchmark for 50 filtered cards testing TargetPool reuse, downscaled separable blur, and live RenderStats HUD.
