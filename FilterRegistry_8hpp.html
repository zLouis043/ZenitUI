Detailed Description

Post-processing filter registry and the filter execution context.

A "filter" is a named post-processing effect applied to a node's rendered layer (the off-screen target produced by Layout::drawLayer). Filters are declared in CSS via filter: blur(4px) drop-shadow(2, 2, 4, black) and resolved at draw time through this registry.

Four execution patterns are supported:

  • SinglePass: one shader, one draw. Used for effects that need only the source target (drop-shadow with a single offset, custom blurs, …).
  • Separable: two passes (horizontal then vertical). Efficient for Gaussian-style blurs. Uses scratch as the intermediate target.
  • Silhouette: draw the source offset by dx/dy through a colour shader, then the source on top. Used by drop-shadow.
  • Custom: a std::function invoked directly.
