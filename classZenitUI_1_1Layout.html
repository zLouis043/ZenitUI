Detailed Description

The base node type: tree, style, layout, input, scroll, render.

See the file-level documentation for a description of the four main passes and the composition points for subclasses.

Note
Layout is not intended to be instantiated directly in user code; use std::make_shared<Layout> for layout containers (VStack, HStack, Stack) or TLayout<Derived>::create for custom components.
Examples
04b_imperative_animations/main.cpp, 11_ref_list/main.cpp, and 12_bindable/main.cpp.

Construct a node with the given layout strategy.

Defaults: interactive = 1, enabled = 1, subtreeDirty = 1, pendingTransition = 1. Style is lazily initialized on first update / measure.

◆ ~Layout()

virtual ZenitUI::Layout::~Layout ( )
inlinevirtual

Destroy the node and clean up framework-side references.

Clears the global pointers (pressTarget, releaseTarget, topmostConsumer, hoverTarget) if they pointed to this node, and releases any render targets owned by a layer draw.

Does not detach children: the parent owns children via shared_ptr, so a child's lifetime is tied to the parent unless reparented.

◆ hitTest()

Layout * ZenitUI::Layout::hitTest ( Vec2 p,
bool ancestorBlocked = false,
const Rect * clipLocal = nullptr )

Hit-test a point against this subtree.

Traversal order matches paint order reversed: front-most first. Within a node, stacking-context children are checked before normal-flow children; negative-Z children last. The self-rect is checked after all children, so a child always wins over its parent.

Parameters
pPoint in screen space.
ancestorBlockedtrue if an ancestor already rejected the point.
clipLocalOptional clip rect in this node's local space.
Returns
The frontmost interactive (or blocksRaycast) node under p, or nullptr.

◆ update()

virtual void ZenitUI::Layout::update ( float dt,
bool ancestorBlocked = false,
bool scrolling = false )
virtual

Per-frame update: input, style, animation, then recurse into children.

This is where the frame begins for a subtree. The recursion passes down two propagated flags:

  • ancestorBlocked: any ancestor disabled, animating a blocking animation, or non-interactive with blocksRaycast on.
  • ancestorScrolling: any ancestor is scrolling; children freeze their hover/press state so a drag does not flicker buttons.

After the recursion, the node fires its own input callbacks, its own onUpdate, and culling of any child that set wantsRemoval.
