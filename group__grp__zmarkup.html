Detailed Description

Declarative UI construction, reusable components, and reactive bindings.

Key concepts:

  • Building trees: parse inline strings with ZMarkup::build or files with ZMarkup::loadMarkupFile.
  • Addressing nodes: use #id for global CSS/lookup IDs (UINode::find) and @ref for local template handles (UINode::ref, UINode::refAll).
  • Prefabs & slots: register reusable templates with ZMarkup::registerPrefab and inject caller children via anonymous or named <Slot> elements.
  • Structural & reactive UI: use If / Each (with keyed reconciliation) together with Bindable<T> and WeakUINode for cycle-free updates.

Live examples: 06_zmarkup · 11_ref_list · 12_bindable · 13_prefabs

Live examples
  • 06_zmarkup — Declarative UI tree built with ZMarkup::build, external ui.zstyle styling, typed #id lookup, and event callbacks.
  • 11_ref_list — Logic-only &#64;ref handles and refAll<T>() for wiring repeated elements in dynamic lists without unique #ids.
  • 12_bindable — Reactive model-to-UI synchronization with Bindable<T>, RAII subscriptions, fireImmediately, and weak_ptr lifetime safety.
  • 13_prefabs — Reusable ZMarkup prefabs with ZMarkup::registerPrefab and Slot child injection.
