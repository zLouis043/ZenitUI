Detailed Description

Lightweight, replaceable logging facility used across ZenitUI.

The logger is intentionally minimal: a single global ILogger sink that receives LogMessage records. Applications can replace the default ConsoleLogger with their own implementation by calling Logger::set.

Free functions logDebug, logInfo, logWarn, logError are the intended entry points. They take the source location as explicit parameters so the macros that use them can inject __FILE__, __LINE__, etc. without polluting the call site.
