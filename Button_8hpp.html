Detailed Description

A clickable button with an optional text label.

The visual is delegated to the base Panel (background, border, radius, shadow all come from Panel / Button theme rules). The button only adds:

  • interactive + focusable + keyboard-activatable configuration;
  • a single Text child whose content can be queried / set via text() / setText().
Note
The text child is the first child if it is a Text instance. setText will not touch a non-Text first child; it will add a new Label at the end instead. This means adding an icon as the first child will silently break setText updates — set the label first (as Btn does), or use the Button::setText return value to check for success.
