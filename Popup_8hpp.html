Detailed Description

An anchored floating panel with close-on-outside and close-on-Escape.

A Popup is a Panel subclass that:

  • sets portal = true (draws and hit-tests above everything else);
  • is hidden by default (enabled = false, opacity = 0);
  • on open, sizes itself to its content's measured size and positions itself adjacent to an anchor widget (or at a screen position);
  • auto-flips above / below the anchor when there is not enough room;
  • closes itself on outside-click or Escape when configured to do so.

The popup never participates in the parent layout: its arrange override is a no-op, and it takes full ownership of its own rect via onUpdate.

Note
openAbove sets a flag but does not measure anything: the actual positioning decision happens in onUpdate on the next frame, once the content has been measured. This two-step design lets a popup adapt to content that is only known after the first measure pass.
