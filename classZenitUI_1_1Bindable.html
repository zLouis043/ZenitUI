◆ set()

template<typename T>
void ZenitUI::Bindable< T >::set ( T v)
inline

Replace the value and notify subscribers if it changed.

Equality is compared on T; setting the same value is a no-op. Subscribers are snapshotted before dispatch, so a subscriber that (un)subscribes from within its callback does not invalidate the loop.

Examples
00_demo/main.cpp, and 12_bindable/main.cpp.
