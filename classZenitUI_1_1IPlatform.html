Detailed Description

Abstract windowing, timing, input, and clipboard backend.

Polled once per frame by UIContext::beginFrame(). See Writing a Custom Backend for invariants and Backends, UTF-8 & Debugging for reference implementations (RaylibPlatform, MockPlatform).

Return the current pointer position (logical pixels), scroll wheel delta, and button states.

Edge-triggered fields (ButtonState::pressed, ButtonState::released, PointerState::wheelY) must fire for one frame only; ButtonState::down stays true while held.

Implemented in ZenitUI::RaylibPlatform, ZenitUI::SDL3Platform, and ZenitUI::Test::MockPlatform.

◆ pollInputEvents()

virtual InputEvents ZenitUI::IPlatform::pollInputEvents ( )
pure virtual

Drain and return keyboard events queued since the previous frame.

InputEvents::chars and InputEvents::keys are edge-triggered (one frame); InputEvents::held lists keys currently held down for repeat handling.
