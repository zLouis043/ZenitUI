Detailed Description

A multi-line UTF-8 editable text area with word wrapping and vertical scrolling.

TextArea is a single Stack node that renders its own wrapped visual lines, selection highlights, blinking caret, placeholder, and internal scrollbar.

Editing model:

  • Text is stored as UTF-8 (std::string); cursor movement, deletion, word jumps (Ctrl+Arrow/Backspace/Delete), double-click selection, click-to-caret, and soft word-wrapping all operate on grapheme-cluster boundaries via ZenitUI::Utf8.
  • Enter inserts a \n newline while keeping focus; Escape releases focus.
  • Supports Ctrl+A/C/X/V clipboard operations (normalizing \r\n / \r to \n), Ctrl+Z/Y (and Ctrl+Shift+Z) 50-step undo/redo history, and mouse-wheel scrolling that yields to parent scroll containers at bounds.
