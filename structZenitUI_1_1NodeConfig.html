Detailed Description

Static configuration bits: interaction behaviour, render behaviour.

Set by subclass constructors (or by inline setters) and read on every frame. Changing any of these fields is safe at runtime, but should be done through the setter methods rather than by writing the bitfields directly, so that bookkeeping (dirty flags, focus cleanup) stays consistent.
