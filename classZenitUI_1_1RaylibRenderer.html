◆ measureCodepoint()

Vec2 ZenitUI::RaylibRenderer::measureCodepoint ( FontHandle f,
uint32_t codepoint,
float size,
float spacing )
overridevirtual

Measure the advance width and height of a single Unicode codepoint.

Default implementation encodes codepoint as UTF-8 and delegates to measureText. Backends with direct glyph tables (e.g. RaylibRenderer) can override for O(1) lookup without string allocation.
