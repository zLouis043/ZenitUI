Detailed Description

A portal-based hover label.

Style tag: "Tooltip". Portal by default. Not interactive, does not block raycast. arrange() is a no-op; the tooltip positions itself via onUpdate once the label has been measured.

std::shared_ptr< Tooltip > ZenitUI::UI::Tooltip::attach ( std::shared_ptr< Layout > owner,
std::string text,
float showDelay = 0.4f )
inlinestatic

Attach a tooltip to owner.

Installs onHoverEnter / onHoverExit handlers on owner (chaining any previous ones) so that hovering the owner shows the tooltip after showDelay and leaves immediately. The tooltip is added as a child of owner; this is what makes its lifetime safe.

Parameters
ownerNode to attach to. Must be non-null.
textText to display.
showDelaySeconds the pointer must remain over the owner before the tooltip appears. 0 shows instantly on hover.
Returns
The created tooltip, for further customization.
Examples
00_demo/main.cpp, and 08_portals/main.cpp.

◆ onUpdate()

void ZenitUI::UI::Tooltip::onUpdate ( float dt)
inlineoverrideprotected

Count down the delay and position the tooltip.

Positioning: centered above the anchor, offset 6 px. Flips below if the top would be clipped, and clamps to the viewport on both axes. Runs every frame while visible (or hovering).
