Detailed Description

Parse a single CSS-like declaration (key: value) into a Style.

Two entry points:

  • applyStyleAttr(st, key, value): the low-level dispatch, handles both attribute-style markup (width="50") and CSS declarations (width: 50px).
  • resolveUnresolvedProps(unresolved, customProps): late-binding of var(--name) references, called from StyleResolver::resolveFor after the cascade has resolved which custom properties are in scope.

The detail namespace contains the calc()-style expression parser and a few small string helpers that are not part of the public API but are used by applyStyleAttr.
