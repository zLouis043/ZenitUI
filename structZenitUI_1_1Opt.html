Detailed Description

template<typename T>
struct ZenitUI::Opt< T >

Optional wrapper with value semantics used for all style fields.

Unlike std::optional, Opt<T> stores the value inline and is cheap to copy even for large T. The is_set flag distinguishes "not declared" from "declared to the default". This distinction is what allows the stylesheet cascade to work without a separate presence bitmask.
