Detailed Description

A virtualized list.

Style tag: "VirtualView". Extends ScrollView (Vertical). Item nodes are added as absolutely-positioned children of the view; the view itself does not lay them out — their top and height come from cumulativeHeights at materialization time.

Fired each time an item node is materialized.

Useful for wiring per-item callbacks that need to see the node identity. Not fired on re-materialization (when scrolling back to an item that was previously unmaterialized, the callback fires again).
