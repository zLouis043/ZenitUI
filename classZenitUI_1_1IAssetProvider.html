Detailed Description

Abstract name-based lookup and runtime lifecycle for fonts, textures, and shaders.

Lookup methods (getFont, getTexture, getEffect) are called frequently during layout and draw; implementations should avoid heap allocations (e.g. via transparent std::string_view hashing). Return a default-constructed invalid handle (id == 0) when a requested asset is not registered.

See Writing a Custom Backend and Backends, UTF-8 & Debugging (RaylibAssetProvider, MockAssetProvider).
