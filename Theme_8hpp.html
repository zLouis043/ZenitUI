Detailed Description

Global stylesheet storage and rule matching.

A Theme holds:

  • the parsed rule list, indexed by tag / last symbol for fast lookup;
  • the :root style used as fallback for inherited properties;
  • the @keyframes registry, keyed by animation name;
  • a monotonically increasing version used to invalidate caches.

StyleParser populates a Theme via addRule / addKeyframes. The StyleResolver reads it to compute per-node styles. Multiple Theme instances are technically supported, but the resolver and most components reference Theme::get() (the global).
