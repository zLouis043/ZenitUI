Detailed Description

Structured diagnostics for the CSS parser and style resolver.

The style subsystem can produce errors, warnings and informational messages with source spans, severities, machine-readable codes, optional "did you mean" suggestions, and cross-references to related spans.

The DiagnosticSink interface decouples reporting from consumption: the parser writes to any sink, tests can use CollectingDiagnosticSink, and production code can use NullDiagnosticSink to discard everything.

loadStyleString / loadStyleFile (in StyleParser.hpp) accept an optional sink and return false if any error was reported.
