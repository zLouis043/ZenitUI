Detailed Description

template<typename T>
class ZenitUI::Bindable< T >::Subscription

RAII handle to an onChanged registration.

Move-only. Destruction (or explicit unsubscribe) removes the callback from the owning Bindable. Safe to destroy after the Bindable has already been destroyed: the shared ControlBlock outlives both.
