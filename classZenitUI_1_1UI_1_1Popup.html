Detailed Description

A floating, anchored panel.

Style tag: "Popup". Portal by default. Content is whatever you pass to setContent.

Close the popup, if it is open.

Fades out via inline style transition, disables the popup, and fires onClose. No-op if already closed.

◆ onUpdate()

void ZenitUI::UI::Popup::onUpdate ( float )
inlineoverrideprotected

Reposition, resize, and close-on-outside / Escape.

Runs every frame while open. Positions the popup based on the anchor's current rect (or pos_ if opened with openAt), flips if necessary, and clamps to the viewport. Fires the configured close behaviours.

Set the popup's content.

Replaces any previous content.

The content is added as a child of the popup; its measured size determines the popup's size on the next frame.
