Detailed Description

Composable set of Unicode codepoints for static font-atlas baking.

Provides common language/symbol presets (ascii, defaultLatin, latinExtendedA, greek, cyrillic, symbols) plus fluent builders (addRange, addCodepoint, addFromUtf8, merge) that produce a sorted, deduplicated std::vector<int> suitable for backends like Raylib's LoadFontEx.
