Detailed Description

Offset, bounds, velocity and drag anchors for one scroll container.

The offset is in content space (pixels scrolled). maxScroll is the maximum valid offset, computed by ScrollController::updateMaxScroll from the content size and the viewport size.

Inertia uses an exponential decay tuned for 60 Hz but made frame-rate-independent by raising the decay to dt * 60.

◆ tickInertia()

void ZenitUI::ScrollState::tickInertia ( float dt)
inline

Advance the inertial offset by dt seconds.

Applies the current velocity to offset, then decays the velocity by pow(DECAY, dt * 60) so that behavior is frame-rate-independent. Velocity below VELOCITY_MIN snaps to zero to avoid infinite asymptotic motion. Clamps the result to [0, maxScroll].
