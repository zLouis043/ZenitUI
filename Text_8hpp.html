Detailed Description

A text-rendering node with optional wrapping and ellipsis.

Text layout is done in one of two modes:

  • Single line (wrap_ == false, or white-space: nowrap): each explicit \n starts a new line; the node's intrinsic width is the widest of those lines.
  • Wrapped (wrap_ == true, default white-space: normal): each logical line (split on \n) is further broken at spaces, and a single word that is wider than the available width is broken into chunks via binary search over prefix lengths.

Both modes are cached: measureSingleLine / measureWrapped keep the wrapped lines vector and a cachedSize until text_dirty or a relevant style value changes. onLayout re-wraps when the available width changes, which can happen after the first arrange — this is why Text overrides onLayout at all: measurement can use one width, layout uses another.

Ellipsis (text-overflow: ellipsis) is applied at draw time only, in renderContent: it does not change the layout box. This matches CSS and means getRect() is unaffected by truncation.
