Detailed Description

Reference IRenderer backed by a batched OpenGL 3.3 Core 2D pipeline.

Uses the same GLSL 330 fragment-shader interface (fragTexCoord, fragColor, texture0, colDiffuse, finalColor) as RaylibRenderer so shader assets in assets/shaders/ run unmodified on both backends.

Note
Must be constructed with an active OpenGL 3.3 Core context on window and destroyed before SDL_GL_DestroyContext.
