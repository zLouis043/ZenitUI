Detailed Description

A length expression: either a sum of unit terms or an AST node.

Two representations coexist:

  • Linear form: terms holds a sum of coeff * unit contributions (e.g. 50% + 10px). Resolved in one pass by resolveH/resolveV.
  • AST form: op != None and args holds the operands (e.g. clamp(0px, 50%, 100vw)). Resolved recursively.

isAuto() returns true when both terms is empty and op == None, which the layout system treats as "size to content".

Arithmetic operators (+, -, *, /) preserve the representation: adding two linear values merges their term lists; adding anything to an AST node produces a new AST node.
