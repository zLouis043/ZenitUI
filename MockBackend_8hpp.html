Detailed Description

Headless mock backend (MockRenderer, MockPlatform, MockAssetProvider) and RAII test harness (ZenitUI::Test::Env).

Serves a dual purpose:

  1. Unit-test harness: drives ZenitUI's full frame cycle (updateTree, measure, arrange, draw) deterministically without opening a window or GPU context, recording draw calls, clip rects, transforms, and shader uniforms for assertions.
  2. Minimal backend skeleton: demonstrates the smallest contract an IPlatform / IRenderer / IAssetProvider triplet must satisfy. Notice in particular:
    • IRenderer::supports(Feature) lets a minimal backend opt out of shaders and off-screen targets simply by returning false.
    • IPlatform::pointer() and pollInputEvents() must clear edge-triggered fields (pressed, released, wheelY, keys, chars) once polled.
    • IRenderer::pushClip() / popClip() must maintain an intersected clip stack so getClipRect() remains accurate for culling.
