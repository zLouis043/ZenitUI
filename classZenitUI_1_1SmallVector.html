Detailed Description

template<typename T, std::size_t N>
class ZenitUI::SmallVector< T, N >

A vector whose first N elements live inside the object.

Template Parameters
TElement type. Must be default-constructible for the inline array.
NNumber of elements stored inline before a heap allocation is made.

Behaves like std::vector<T> but avoids a heap allocation for small payloads (typically 2–8 elements). When size() exceeds N, the inline contents are moved into an internal std::vector and all further growth uses that heap buffer.

The inline_ array is always present, so the object size is at least N * sizeof(T). Choose N accordingly.

Note
Copy and move operations are defaulted and forward to the inline array and the internal heap vector as appropriate. The inline → heap promotion is not exception-safe against throwing move constructors of T; for trivially-copyable element types (the intended use case) this is irrelevant.
Warning
Iterators returned by begin()/end() are invalidated whenever the vector transitions from inline to heap storage, and on the usual heap reallocation.
