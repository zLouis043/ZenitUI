Detailed Description

Property transitions, @keyframes, imperative animations, and post-processing filters.

Key concepts:

  • Transitions: opt-in per node (transition-time: 0s by default); set transition in .zstyle to smoothly interpolate across state changes.
  • Keyframe & imperative animations: declare @keyframes in .zstyle or register a UIAnimation via Layout::addAnimation / playAnimation.
  • Filters & shaders: apply filter: blur(...) drop-shadow(...) or register custom post-processing passes in FilterRegistry. Off-screen targets are automatically pooled by UIContext::targetPool.

Live examples: 04_animations · 04b_imperative_animations · 07_effects · 07b_effects_stress

Live examples
  • 04_animations — Declarative animation channels in .zstyle: state transitions, &#64;keyframes, and ::part animations.
  • 04b_imperative_animations — Event-driven imperative UIAnimation timelines: play/reverse, custom math tracks, and weak_ptr-safe chaining via onFinished.
  • 07_effects — Post-processing with CSS filter chains (blur, drop-shadow, custom sepia via FilterRegistry) vs single-pass shader effects.
  • 07b_effects_stress — GPU stress benchmark for 50 filtered cards testing TargetPool reuse, downscaled separable blur, and live RenderStats HUD.
  • 10_canvas — Explicit offscreen composition with CanvasLayout, comparing an unshaded target against a whole-canvas shader via setShader().

◆ evaluateKeyframes()

Style ZenitUI::evaluateKeyframes ( const KeyframeAnimation & anim,
float localT,
TransitionFunction ease )
inline

Interpolate a KeyframeAnimation at local time localT.

Finds the two keyframes bracketing localT, computes the local sub-progress, applies easing, then lerps every property present in both bracketing keyframes. Properties present in only one side are taken from that side directly.

Case-insensitive; separators -, _ and space are ignored, so "ease-in-out-quad", "EaseInOutQuad" and "ease in out quad" all parse to TransitionFunction::EaseInOutQuad.
