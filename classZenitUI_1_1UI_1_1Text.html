Detailed Description

A read-only text node.

Style tag: "Text". Not interactive. Emits no :hover / :pressed states — wrap the text in a Panel or a Button if you need those.

Examples
06_zmarkup/main.cpp, 11_ref_list/main.cpp, and 12_bindable/main.cpp.

Compute the intrinsic size for the current content.

Wrapping requires an available width; if none is given (availW <= 0), falls back to single-line measurement. The wrap flag is combined with white-space: nowrap, so a nowrap style wins over a setWrap(true) call.

Reimplemented from ZenitUI::Layout.

◆ onLayout()

void ZenitUI::UI::Text::onLayout ( )
inlineoverrideprotectedvirtual

Re-wrap when the available width differs from the cached one.

Measurement uses whatever width the parent passes at measure time, but the final rect is assigned in arrange, and the two can differ (e.g. a percent(100) parent measured against a larger hypothetical and then arranged against the real parent). This hook reconciles the two.

Reimplemented from ZenitUI::Layout.

inlineoverrideprotectedvirtual

Draw the text, applying ellipsis if configured.

The clip rect is the node's full rect, not the inner content box, so overshooting glyphs (accents, italics, emoji) are visible even when the text bounds report otherwise. Padding and border are subtracted from the text origin, not from the clip.

Note
align-items (or text-align if set) controls horizontal alignment within the content box; vertical-align controls vertical alignment of the text block as a whole.

Reimplemented from ZenitUI::Layout.
