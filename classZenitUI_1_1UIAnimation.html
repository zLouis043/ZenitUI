Detailed Description

A time-parameterised sequence of per-property tracks.

Each track pairs a start and end value with a setter callback that writes the interpolated value into the target Layout. The setter is type-erased behind TrackBase, so UIAnimation can hold tracks of different value types (e.g. float opacity and Value translateY).

Duration and delay are in seconds. blocksInput, if set, is reported back to Layout::update via AnimationPlayer::tickImperative and blocks input to the subtree for the animation's whole lifetime.
